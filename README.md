# Розвиваючі ігри "Крош та друзі" 🌟

Інтерактивна веб-платформа розвиваючих ігор для малюків. Проект розроблено з акцентом на сучасний дизайн, інтерактивність та максимальне залучення уваги дитини.

## 🎮 Доступні ігри

На дашборді наразі доступна базова гра **"Математика з Крошем"**, де дитина може навчитися:
- Рахувати предмети (Скільки кульок? Скільки яблук?)
- Порівнювати числа (Більше/Менше)
- Знаходити логічні послідовності (Продовж ряд)
- Порівнювати кількість (Де більше ягід?)

Інші ігри ("Логіка з Їжачком" та "Кольори з Нюшею") знаходяться в розробці.

## ✨ Особливості платформи

* **Сучасний Dashboard:** Яскравий стартовий екран для зручного вибору гри.
* **Гендерна нейтральність:** Гра адаптована для всіх дітей завдяки універсальним зверненням ("дітям", "Привіт, друже!", "Супер робота!").
* **Звукові ефекти (Web Audio API):**
  * Приємний клік при натисканні на кнопки.
  * Радісна мелодія при правильній відповіді.
  * М'який звук-підказка при помилці (без стресу для дитини).
  * Тріумфальна фінальна мелодія.
* **Візуальні ефекти:**
  * Генератор конфетті при кожній правильній відповіді.
  * Спливаючі підбадьорливі банери "Молодець! 🌟".
  * Плавні анімації карток та кнопок при наведенні.
* **Адаптивність:** Інтерфейс автоматично підлаштовується під будь-який розмір екрану (дотримуючись пропорцій малюнків).

## 🚀 Як запустити

Проект не потребує жодних серверів або складних налаштувань. Усе працює прямо в браузері!

1. Відкрийте папку проекту.
2. Двічі клікніть на файл `index.html`.
3. Сторінка відкриється у вашому браузері за замовчуванням (рекомендується Google Chrome, Safari або Firefox).

## 🛠 Технології

* **HTML5:** Структура платформи та ігрових слайдів.
* **CSS3:** Сучасна верстка (Flexbox, CSS-змінні, ключові кадри анімацій, градієнти, тіні).
* **Vanilla JavaScript:** Повна логіка гри, генерація конфетті на Canvas, синтез звуків.
* **Canvas API:** Рушій для відтворення фізики падаючого конфетті.
* **Web Audio API:** Програмна генерація чистих звукових хвиль без використання зовнішніх аудіофайлів.
